ngx-numeric-range-form-field demo

Numeric range input built on Angular 21 @angular/forms/signals. Two number fields share a composite value and plug into a parent form() schema via [formField]. No ControlValueAccessor, no Angular Material.

Basic range

Defaulted value, reset affordance, numericRangeOrderValid enforces max ≥ min.
