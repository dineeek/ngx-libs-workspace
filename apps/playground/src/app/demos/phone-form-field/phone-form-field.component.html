ngx-phone-form-field demo

International phone number input built on Angular 21 @angular/forms/signals. Country picker (with flags + search) and national-number input share a single E.164 string value via [formField]. AsYouType formatting via libphonenumber-js/max. No ControlValueAccessor, no Angular Material.

All countries available, auto-detected initial country. Validator: phoneValid(p).
