ngx-time-range-form-field demo

Time range input built on Angular 21 @angular/forms/signals. Two <input type="time"> fields share a composite { start, end } value and plug into a parent form() schema via [formField]. No ControlValueAccessor, no Angular Material.

Basic range

Defaulted value, reset affordance, timeRangeOrderValid enforces end ≥ start.

Validated workday slot

required(p) + timeRangeBounds + timeRangeWidth + timeRangeOrderValid. Bounds clamp the slot to 08:00..20:00; the span must be at least 30 minutes and at most 8 hours.
