ngx-overflow-tooltip demo

A standalone Angular directive that flags whether an element's text is ellipsized. Re-measures via ResizeObserver on layout changes and MutationObserver on content changes, with rAF coalescing. Headless — compose with any tooltip surface, or just toggle a "Read more" affordance.

Single-line ellipsis

Each cell uses text-overflow: ellipsis. The ⓘ badge and the native title attribute only attach when the directive's isTruncated() signal is true.

@for (row of singleLineRows(); track row.id) {
{{ row.name }} @if (nameOft.isTruncated()) { ⓘ } {{ row.id }} @if (idOft.isTruncated()) { ⓘ }
}

Multi-line clamp

[ngxOverflowTooltip]="'multi'" only watches vertical overflow. The "Read more" toggle appears only when the clamped text actually has hidden content.

{{ description() }}

@if (multiOft.isTruncated() || multiExpanded()) { }

MutationObserver in action

Type into the input — the rendered <span> is re-measured on every text change so the truncation badge appears / disappears live, without you wiring an extra (input) handler.

{{ liveText() }} {{ liveOft.isTruncated() ? 'truncated' : 'fits' }}

Composition with Angular Material

Recommended pairing — MatTooltip only fires when the directive's signal flips. The lib itself does not depend on @angular/material.
