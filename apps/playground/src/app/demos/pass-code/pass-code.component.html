ngx-pass-code demo

Three live showcases of the component's inputs (type, uppercase, autoblur, pattern validation). Every value is a plain signal() wrapped in form() — the library plugs in via [formField].

Text code

5 uppercase letters or digits. Demonstrates uppercase + pattern + required + autofocus.

    @for (b of textBadges; track b) {
  • {{ b }}
    • }
  • {{ textForm().valid() ? 'Valid' : 'Invalid' }}
  • {{ textForm().touched() ? 'Touched' : 'Untouched' }}
  • value: {{ textValue() | json }}
