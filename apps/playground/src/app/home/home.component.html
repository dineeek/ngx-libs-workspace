ngx-pass-code

Reactive Angular custom form control for OTP / pass-code input — one box per character, with validation, autofocus and autoblur. Built for Angular 21 Signal Forms.

Try the demo → View on npm ↗

What you get

  • One input box per character with auto next / previous navigation
  • Plugs into Angular form() via [formField]
  • Schema-driven validation (required, pattern, validate)
  • Autofocus first input, autoblur last, type=password masking
  • Standalone, tree-shakable, zero runtime dependencies
